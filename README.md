# Royal Indian 3D Wedding Invitation - Ishaan & Anaya

A modern, mobile-first 3D Indian royal wedding invitation web experience created with Three.js.

## Features
- 3D Walkthrough Intro (temple doors open, camera glides along candlelit corridors to the balcony overlooking the illuminated lake palace).
- Floating hero invitation card with gold calligraphy for Ishaan & Anaya.
- Smooth scroll cross-fade to a blurred romantic palace couple background.
- Card-less floating sections:
  - Save our Date & Auspicious Muhurat
  - Interactive Countdown Timer
  - Wedding Ceremonies & Celebrations Timeline
  - Venue & Location with direct Google Maps link
  - Family warm regards & helpline
- Background audio player with single-tap mute/unmute toggle.
